# Admin

The Admin section contains four pages:

* [**Git Targets**](git-targets.md): manage personal and shared Git repository connections, including the ability to mark targets as shared for all users.
* [**Cluster Readiness**](cluster-readiness.md): check environments for deployment prerequisites, and enable or disable environments from self-service entirely.
* [**Runtime updates**](runtime-updates.md): redeploy applications on the latest image of their runtime, for example after a security release.
* [**Settings**](settings.md): for Portainer-Run's configuration.

Non-admin users don't see this section in the navigation at all. See [Roles and RBAC](../../architecture/roles.md) for how Portainer-Run derives admin status from Portainer itself.
